Réglages dans le fichier index.html

En haut du script, dans le bloc RÉGLAGES, vous pouvez modifier :

  • CODE_ENSEIGNANT : le code de cet espace.
  • DIGIPAD_URL : le lien du Digipad de la classe (le bouton apparaît chez les élèves).
  • ENTREPRISES : la liste des lieux de stage de la classe (nom, secteur, ville). Les élèves la retrouvent dans un menu déroulant à l'étape 1. N'y mettez pas les noms des élèves : la page est publique.

Le code enseignant protège l'affichage, pas les données : les élèves pourraient le trouver dans le code de la page. Les réponses ne sont pas sur ce site, elles restent dans les fichiers de sauvegarde.
